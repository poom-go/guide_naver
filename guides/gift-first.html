최초 주문 기준

ℹ️
최초 주문 기준 증정은 해당 고객사 스토어에서 처음 구매하는 신규 고객에게 사은품을 동봉하는 방식입니다.
기능 개요

고객의 첫 구매 여부를 기준으로 사은품을 증정합니다. WMS 또는 주문 시스템에서 신규 고객 여부가 자동으로 표시되어야 하며, 표시가 없는 경우 고객사에 신규 고객 판별 기준을 확인해야 합니다. 재구매 고객에게 오동봉되지 않도록 주의가 필요합니다.

⚠️
처리 전 아래 사항을 반드시 확인하세요. 누락 시 사은품 오동봉 또는 미동봉이 발생할 수 있습니다.
처리 전 준비사항
1
신규 고객 판별 기준 확인
WMS에서 신규 고객 표시 여부와 판별 기준(첫 주문 여부, 가입 후 첫 구매 등)을 확인합니다.
2
WMS 자동 표시 여부 확인
피킹지시서에 신규 고객 여부가 자동 표시되는지 확인합니다.
3
사은품 재고 확인
최초 주문 사은품 재고가 충분한지 확인합니다.
4
중복 증정 방지 확인
동일 고객이 반복 주문 시 최초 1회만 증정되는지 WMS 설정을 확인합니다.
5
적용 기간 확인
최초 주문 사은품 프로모션 적용 기간을 확인합니다.
✅
출고 후 WMS에서 사은품 재고 차감까지 확인해야 재고가 정확히 관리됩니다.

WMS 피킹지시서에서 해당 주문이 신규 고객 첫 주문 건인지 확인합니다.

STEP 2사은품 피킹

신규 고객 확인 주문에 한해 최초 주문 사은품을 피킹합니다.

📷 박스 내 동봉 화면

일반 출고와 동일하게 처리합니다.

WMS에서 재고 차감을 확인하고, 해당 고객의 사은품 증정 이력이 기록되었는지 확인합니다.

📷 사은품 재고 차감 및 이력 확인 화면
자주 하는 질문
고객사에 해당 주문의 신규 고객 여부를 확인 요청합니다. 확인 전까지 사은품 동봉을 보류하고, 확인 후 별도 발송 또는 미증정 처리합니다.
최초 1건에만 사은품을 동봉합니다. WMS에서 첫 번째 주문 건에 신규 고객 표시가 있는 건을 기준으로 합니다.
고객사에 즉시 재고 소진 사실을 안내합니다. 재고 보충 후 별도 발송 여부는 고객사 정책을 따릅니다.
고객사에 즉시 보고합니다. 이미 출고된 건이라면 재고 처리 방식을 고객사와 협의합니다. 재발 방지를 위해 WMS 설정을 재확인합니다.
중복 적용 여부는 고객사 정책을 따릅니다. 일반적으로 각 조건에 해당하는 사은품을 모두 동봉합니다. 불확실하면 고객사에 확인합니다.
