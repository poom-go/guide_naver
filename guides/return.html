반품

ℹ️
반품은 고객이 수령한 상품을 창고로 회수하는 프로세스입니다. 반품 사유 및 상품 상태에 따라 양품·불량 처리가 결정됩니다.
기능 개요

고객 반품 요청 접수 후 택배 회수 → 입고 검수 → 양품/불량 분류 → WMS 재고 반영 순으로 처리합니다. 반품 사유는 단순변심, 오배송, 상품불량으로 구분되며 사유에 따라 배송비 처리 기준이 다릅니다. 검수 완료된 양품은 판매 가능 재고로 복귀되며, 불량품은 별도 불량 로케이션에 보관합니다.

⚠️
반품 접수 전 고객사로부터 반품 승인 번호를 반드시 확인하세요. 미승인 반품 건은 입고 처리 보류합니다.
처리 전 준비사항
1
반품 승인 여부 확인
WMS > 반품관리에서 해당 주문의 반품 승인 상태를 확인합니다. 승인되지 않은 건은 고객사 확인 후 처리합니다.
2
반품 사유 파악
단순변심, 오배송, 상품불량 중 어떤 사유인지 확인합니다. 사유에 따라 검수 기준과 배송비 처리가 달라집니다.
3
검수 기준표 확인
고객사별 반품 검수 기준이 다를 수 있습니다. 해당 고객사의 양품 기준(포장 상태, 사용 여부, 구성품 확인 등)을 사전에 숙지합니다.
4
검수 공간 및 자재 준비
반품 검수대, 불량 표시 스티커, 카메라(파손 사진 촬영용)를 준비합니다. 검수 결과를 기록할 반품 검수서 양식도 준비합니다.
5
불량 로케이션 공간 확인
불량 처리 예상 물량에 맞는 보관 공간이 확보되어 있는지 사전 확인합니다.
✅
검수 완료 후 WMS 반영까지 완료해야 재고가 정확히 업데이트됩니다.
처리 과정
STEP 1반품 택배 수령

반품 택배가 도착하면 송장 번호를 스캔하여 WMS에서 해당 반품 건을 확인합니다. 박스 외관 파손 여부를 먼저 확인하고 사진으로 기록합니다.

📷 반품 택배 수령 현장 사진
STEP 2개봉 및 내용물 확인

박스를 개봉하여 상품 구성품이 모두 있는지, 사용 흔적이 있는지 확인합니다. 상품 상태를 사진으로 기록합니다.

📷 반품 개봉 검수 사진
STEP 3양품 / 불량 분류

고객사 검수 기준에 따라 양품과 불량으로 분류합니다. 판단이 어려운 경우 고객사 담당자에게 사진을 전송하여 확인을 받습니다.

📷 양품·불량 분류 현장 사진
STEP 4로케이션 입고

양품은 해당 SKU 로케이션에 입고 처리합니다. 불량품은 불량 전용 로케이션에 보관하고 불량 라벨을 부착합니다.

📷 로케이션 입고 처리 사진
STEP 5WMS 반품 처리 완료

WMS에서 반품 입고 처리를 완료합니다. 양품 수량과 불량 수량을 각각 입력하고, 불량 사유를 메모란에 기록합니다. 처리 완료 후 고객사에 결과를 안내합니다.

📷 WMS 반품 처리 완료 화면
자주 하는 질문
미승인 반품 건은 즉시 입고 처리하지 않고 보류합니다. 고객사 담당자에게 연락하여 반품 승인 처리를 요청합니다. 승인 확인 후 정상 프로세스로 진행합니다.
임의 판단하지 말고 사진을 찍어 고객사 담당자에게 확인 요청합니다. 고객사 응답 전까지는 별도 보류 공간에 보관하고 WMS에 보류 상태로 등록합니다.
오입고 상품은 별도 보관하고 고객사에 즉시 안내합니다. 해당 상품의 원 주문 건을 파악하여 처리 방향(반송 또는 보관)을 결정합니다. WMS에 오입고 이력을 기록합니다.
불량품 보관 기간은 고객사별 계약 조건에 따라 다릅니다. 일반적으로 불량 확정 후 30일 이내에 고객사가 처리 방향(폐기, 반송 등)을 결정해야 합니다. 기간 초과 시 고객사에 처리 요청 안내를 발송합니다.
검수 인력이 부족할 경우 즉시 운영팀장에게 보고하여 인력을 추가 배치합니다. 급증 원인(특정 상품 불량, 배송 오류 등)을 파악하여 고객사에 공유하고, 처리 완료 예상 일정을 안내합니다.
