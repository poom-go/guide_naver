반품

기능 개요

고객이 수령한 상품을 창고로 회수하는 프로세스입니다.
반품 사유 및 상품 상태에 따라 양품·불량 처리가 결정됩니다.
수기 접수, 검품 결과 확인, 반품 반출 요청 세 가지 유형으로 구분됩니다.

⚠️
처리 전 아래 사항을 반드시 확인하세요.
처리 전 준비사항
1
반품 승인 여부 확인
WMS > 반품관리에서 해당 주문의 반품 승인 상태를 확인합니다. 승인되지 않은 건은 고객사 확인 후 처리합니다.
2
반품 사유 파악
단순변심, 오배송, 상품불량 중 어떤 사유인지 확인합니다. 사유에 따라 검수 기준과 배송비 처리가 달라집니다.
3
고객사별 검수 기준 확인
고객사별 반품 검수 기준이 다를 수 있습니다. 해당 고객사의 양품 기준(포장 상태, 사용 여부, 구성품 확인 등)을 사전에 숙지합니다.
처리 과정
처리 유형을 선택하면 단계별 과정을 확인할 수 있습니다.
자주 하는 질문
미승인 반품 건은 즉시 입고 처리하지 않고 보류합니다. 고객사 담당자에게 연락하여 반품 승인 처리를 요청합니다. 승인 확인 후 정상 프로세스로 진행합니다.
임의 판단하지 말고 사진을 찍어 고객사 담당자에게 확인 요청합니다. 고객사 응답 전까지는 별도 보류 공간에 보관하고 WMS에 보류 상태로 등록합니다.
오입고 상품은 별도 보관하고 고객사에 즉시 안내합니다. 해당 상품의 원 주문 건을 파악하여 처리 방향(반송 또는 보관)을 결정합니다.
불량품 보관 기간은 고객사별 계약 조건에 따라 다릅니다. 일반적으로 불량 확정 후 30일 이내에 고객사가 처리 방향(폐기, 반송 등)을 결정해야 합니다.
검수 인력이 부족할 경우 즉시 운영팀장에게 보고하여 인력을 추가 배치합니다. 급증 원인을 파악하여 고객사에 공유하고 처리 완료 예상 일정을 안내합니다.
