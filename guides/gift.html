사은품

기능 개요

사은품은 고객사 설정 조건에 따라 출고 시 상품과 함께 동봉되는 증정품입니다.
증정 조건은 아래 유형 중 필요한 조건으로 설정 할 수 있어요.

처리 전 준비사항
1
사은품 재고 수량 확인
현재 보관 중인 사은품 수량이 충분한지 확인해주세요.
2
사은품 재고 부족 시 처리 방안
사은품 재고 부족으로 인한 대체품 또는 제외여부를 등록 시 함께 기재해주세요.
미등록 시 제외 후 본품만 출고 진행되며, 그로 인한 CS가 증가할 수 있습니다.
3
스마트스토어 노출 문구 확인
사은품 증정 시 재고 소진 시 대체 또는 제외되는 내용에 대한 명시가 되어있는지 확인해주세요.
4
용어 설명
컬럼 설명
캠페인명이벤트 명
프로모션명사은품 규칙 명
캠페인 기간프로모션(사은품 규칙)이 적용되어야 하는 주문일시 기간
비례 증정조건 그룹 설정 기준으로 부합할 때 마다 비례로 증정이 필요한 경우 사용
선착순 증정 수량사은품 규칙이 총 몇건의 주문번호로 적용되는지의 대한 수량
랜덤 사은품여러가지 SKU 중 조건 부합 시 랜덤으로 임의 부여하여 출고를 희망할 경우 사용
랜덤 사은품 중복 증정여러가지 SKU가 중복으로 증정되어도 되는 경우 사용
랜덤 증정 수량랜덤 사은품이 증정되어야하는 수량
처리 과정
사은품 유형을 선택하면 단계별 처리 과정을 확인할 수 있습니다.
자주 하는 질문
대부분의 기능을 제공하고는 있으나, 특정 상품만 또는 특정 옵션만 N개 이상 구매시 적용은 불가하며, 랜덤 사은품의 경우 비례 증정이 불가합니다.
사은품이 적용되지 않은 주문번호를 물류지원센터를 통해 문의해주세요. 미적용 사례에 대한 확인 후 답변 받으실 수 있습니다.
각 조건 그룹을 병합하여 규칙을 생성해주셔야합니다.
프로모션 활성화가 되어있더라도, 캠페인 기간이 지난 경우 적용되지 않습니다.
