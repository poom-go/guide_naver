사은품

기능 개요

사은품은 고객사 설정 조건에 따라 출고 시 상품과 함께 동봉되는 증정품입니다.
증정 조건은 전체 대상, 결제 금액, 상품 수량, 옵션 수량, SKU 수량, 최초 주문, 랜덤 7가지로 구분됩니다.
유형을 선택하면 해당 처리 과정을 확인할 수 있습니다.

⚠️
처리 전 아래 사항을 반드시 확인하세요. 오동봉 또는 미동봉 발생 시 고객 불만으로 이어집니다.
처리 전 준비사항
1
사은품 등록 및 활성화 상태 확인
WMS > 사은품관리에서 해당 프로모션이 정상 등록·활성화 상태인지 확인합니다.
2
사은품 재고 수량 확인
현재 보관 중인 사은품 수량이 예상 주문량 대비 충분한지 확인합니다. 재고 부족 시 고객사에 즉시 안내합니다.
3
적용 기간 및 조건 확인
프로모션 시작일·종료일과 증정 조건을 확인합니다. 기간 외 주문 또는 조건 미충족 주문에는 적용하지 않습니다.
4
WMS 자동 표시 여부 확인
WMS 피킹지시서에 사은품 항목이 자동으로 표시되는지 확인합니다. 미표시 시 수동으로 확인하여 동봉합니다.
처리 과정
사은품 유형을 선택하면 단계별 처리 과정을 확인할 수 있습니다.
자주 하는 질문
즉시 고객사에 재고 소진 사실을 안내합니다. 프로모션 중단 또는 대체 사은품 여부를 확인하고 WMS에서 해당 사은품 설정을 비활성화합니다.
누락된 주문 건을 파악하고 해당 고객에게 사은품을 별도 발송합니다. 재고가 있다면 즉시 별도 패키지로 출고하고 고객사에 안내합니다.
WMS 사은품 설정이 정상 활성화 상태인지 확인합니다. 설정이 정상이라면 IT팀에 문의합니다. 해결 전까지 수동으로 확인하여 동봉합니다.
각 조건에 해당하는 사은품을 모두 동봉하는 것이 원칙입니다. 중복 적용 여부는 고객사 정책을 사전에 확인합니다.
즉시 WMS에서 해당 프로모션을 비활성화합니다. 종료일 이후 출고된 건에 사은품이 동봉됐다면 고객사에 보고합니다.
