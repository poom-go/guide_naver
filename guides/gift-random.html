랜덤 사은품

ℹ️
랜덤 사은품은 사전 설정된 사은품 풀(Pool) 중 무작위로 선정하여 동봉하는 방식입니다.
기능 개요

여러 종류의 사은품 중 하나를 무작위로 선택하여 동봉합니다. WMS에서 랜덤 배정 알고리즘에 따라 자동으로 사은품이 지정되거나, 수동으로 사은품 풀 중 하나를 선택하는 방식으로 운영됩니다. 어떤 방식이든 사은품 풀 내 재고 균형을 지속적으로 모니터링해야 합니다.

⚠️
처리 전 아래 사항을 반드시 확인하세요. 누락 시 사은품 오동봉 또는 미동봉이 발생할 수 있습니다.
처리 전 준비사항
1
사은품 풀 목록 및 재고 확인
WMS에 등록된 랜덤 사은품 풀 목록과 각 사은품 재고를 확인합니다.
2
배정 방식 확인
WMS 자동 배정인지 수동 선택 방식인지 확인합니다.
3
재고 균형 확인
특정 사은품만 재고가 과도하게 남거나 부족하지 않은지 균형을 확인합니다.
4
풀 내 사은품 로케이션 확인
각 랜덤 사은품이 지정 로케이션에 보관되어 있는지 확인합니다.
5
적용 기간 확인
랜덤 사은품 프로모션 적용 기간을 확인합니다.
✅
출고 후 WMS에서 사은품 재고 차감까지 확인해야 재고가 정확히 관리됩니다.

자주 하는 질문
해당 사은품을 풀에서 일시 제외하고 나머지 풀로 운영합니다. 고객사에 재고 소진 사실을 안내하고 추가 입고 또는 풀 교체 여부를 확인합니다.
즉시 고객사에 안내하고 프로모션 중단 또는 대체 사은품 입고 여부를 결정합니다. WMS에서 랜덤 사은품 설정을 비활성화합니다.
랜덤 사은품은 선택이 불가함을 고객사를 통해 안내합니다. 특정 상품 지정 요청은 수용하지 않습니다.
WMS 랜덤 배정 설정을 확인합니다. 배정 알고리즘 오류가 의심되면 IT팀에 문의합니다. 임시로 수동 선택 방식으로 전환하여 운영합니다.
WMS 사은품 설정 화면에서 해당 프로모션에 새 사은품 SKU를 추가합니다. 사은품 재고가 입고된 후 로케이션 배치 완료 후 활성화합니다.
