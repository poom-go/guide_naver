결제 금액 기준

ℹ️
결제 금액 기준 증정은 주문 결제 금액이 설정 금액 이상인 경우에만 사은품을 동봉하는 방식입니다.
기능 개요

설정된 기준 금액 이상 결제 주문에만 사은품을 동봉합니다. WMS에서 자동으로 사은품 적용 여부가 표시되지만, 피킹 전 반드시 금액 조건을 재확인해야 합니다. 할인·쿠폰 적용 후 금액 기준인지, 정가 기준인지 고객사 설정을 사전에 확인합니다.

⚠️
처리 전 아래 사항을 반드시 확인하세요. 누락 시 사은품 오동봉 또는 미동봉이 발생할 수 있습니다.
처리 전 준비사항
1
기준 금액 확인
WMS에 등록된 사은품 지급 기준 금액을 확인합니다. 할인 후 금액 기준인지 정가 기준인지 명확히 파악합니다.
2
사은품 재고 확인
현재 사은품 재고 수량이 충분한지 확인합니다.
3
WMS 적용 여부 자동 표시 확인
해당 고객사 설정에서 기준 금액 초과 시 WMS 피킹지시서에 자동 표시되는지 확인합니다.
4
복수 구간 설정 확인
금액 구간별로 사은품 종류가 다를 경우 각 구간 기준을 숙지합니다.
5
프로모션 적용 기간 확인
기준 금액 사은품의 적용 시작일·종료일을 확인합니다.
✅
출고 후 WMS에서 사은품 재고 차감까지 확인해야 재고가 정확히 관리됩니다.
처리 과정
STEP 1주문 결제 금액 확인

WMS 피킹지시서에서 결제 금액을 확인하고 사은품 적용 대상 여부를 판단합니다.

📷 주문 결제 금액 확인 화면
STEP 2사은품 피킹

기준 금액 초과 주문 건에 한해 사은품을 피킹합니다. 금액 구간별로 다른 사은품이 설정된 경우 해당 구간 사은품을 피킹합니다.

📷 사은품 피킹 화면
STEP 3박스 내 동봉

본 상품 포장 시 사은품을 함께 동봉합니다.

📷 박스 내 동봉 화면
STEP 4출고 처리

일반 출고와 동일하게 송장 부착 후 출고 처리합니다.

📷 출고 처리 화면
STEP 5사은품 재고 차감 확인

출고 후 WMS에서 사은품 재고 차감을 확인합니다.

📷 사은품 재고 차감 확인 화면
자주 하는 질문
고객사 설정 기준을 따릅니다. '이상(≥)'으로 설정된 경우 기준 금액과 동일하면 증정합니다. '초과(>)'로 설정된 경우 기준 금액과 동일하면 미증정입니다. WMS 설정값을 확인하세요.
WMS에 등록된 기준(할인 전/후)을 따릅니다. 할인 후 금액 기준이라면 기준 미만이므로 미증정입니다. 불확실할 경우 고객사에 확인합니다.
건별로 각각 기준 금액을 적용하는 것이 원칙입니다. 합산 기준 적용 여부는 고객사 정책에 따르므로 사전 확인이 필요합니다.
WMS에서 즉시 기준 금액을 업데이트합니다. 변경 전후 경계 시점의 주문 건은 고객사와 처리 기준을 협의합니다.
고객사에 재고 상황을 즉시 안내하고 추가 입고 또는 대체 사은품 여부를 확인합니다. 재고 소진 후에는 WMS에서 해당 사은품을 비활성화합니다.
