상품 수량 기준

ℹ️
상품 수량 기준 증정은 주문 내 상품 총 수량이 설정 기준 이상인 경우 사은품을 동봉하는 방식입니다.
기능 개요

주문 건의 총 상품 수량이 설정 기준을 충족할 때 사은품을 동봉합니다. 단일 SKU 수량 기준인지 전체 SKU 합산 기준인지 고객사 설정을 먼저 확인합니다. 수량 구간별로 사은품 종류나 수량이 달라지는 경우 각 구간 기준을 숙지해야 합니다.

⚠️
처리 전 아래 사항을 반드시 확인하세요. 누락 시 사은품 오동봉 또는 미동봉이 발생할 수 있습니다.
처리 전 준비사항
1
수량 기준 확인
WMS에서 사은품 지급 기준 수량을 확인합니다. 합산 수량 기준인지, 특정 SKU 수량 기준인지 파악합니다.
2
사은품 재고 확인
현재 사은품 재고가 충분한지 확인합니다.
3
구간별 사은품 설정 확인
수량 구간별로 다른 사은품이 설정된 경우 각 구간 기준을 숙지합니다.
4
WMS 자동 적용 여부 확인
WMS 피킹지시서에 수량 기준 충족 시 자동으로 사은품 항목이 표시되는지 확인합니다.
5
적용 기간 확인
프로모션 적용 기간을 확인합니다.
✅
출고 후 WMS에서 사은품 재고 차감까지 확인해야 재고가 정확히 관리됩니다.
처리 과정
STEP 1주문 상품 수량 확인

WMS 피킹지시서에서 상품 총 수량을 확인하고 사은품 기준 충족 여부를 판단합니다.

📷 주문 상품 수량 확인 화면
STEP 2사은품 피킹

기준 수량 충족 주문에 한해 해당 사은품을 피킹합니다.

📷 사은품 피킹 화면
STEP 3박스 내 동봉

본 상품 포장 시 사은품을 함께 동봉합니다.

📷 박스 내 동봉 화면
STEP 4출고 처리

일반 출고와 동일하게 송장 부착 후 출고 처리합니다.

📷 출고 처리 화면
STEP 5사은품 재고 차감 확인

WMS에서 사은품 재고 차감을 확인합니다.

📷 사은품 재고 차감 확인 화면
자주 하는 질문
WMS 사은품 설정 화면에서 확인하거나 고객사 담당자에게 확인합니다. 잘못 적용될 경우 누락 또는 과다 증정이 발생합니다.
WMS 설정값(이상/초과)을 확인합니다. '이상'이면 증정, '초과'면 미증정입니다.
묶음 배송 건은 합산 수량을 기준으로 적용하는 것이 일반적입니다. 고객사 정책을 사전에 확인하고 WMS 설정에 따릅니다.
고객사에 즉시 안내하고 추가 입고 또는 대체 여부를 확인합니다. 재고 소진 후에는 WMS에서 해당 사은품을 비활성화합니다.
두 가지 조건을 모두 충족하는 경우 각각 동봉하는 것이 원칙입니다. 중복 적용 여부는 고객사 정책을 사전에 확인합니다.
