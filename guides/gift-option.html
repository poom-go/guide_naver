옵션 수량 기준

ℹ️
옵션 수량 기준 증정은 특정 옵션(색상, 사이즈 등)을 설정 수량 이상 구매한 경우 사은품을 동봉하는 방식입니다.
기능 개요

특정 옵션 SKU의 구매 수량이 기준을 충족할 때 사은품을 증정합니다. 옵션별로 사은품 종류가 다를 수 있으므로 해당 옵션에 매핑된 사은품 정보를 사전에 확인해야 합니다. WMS 피킹지시서에 옵션명과 사은품 정보가 자동 출력되는지 확인이 필요합니다.

⚠️
처리 전 아래 사항을 반드시 확인하세요. 누락 시 사은품 오동봉 또는 미동봉이 발생할 수 있습니다.
처리 전 준비사항
1
대상 옵션 및 기준 수량 확인
어떤 옵션이 사은품 대상인지, 각 옵션의 기준 수량이 얼마인지 WMS에서 확인합니다.
2
옵션별 사은품 매핑 확인
옵션에 따라 사은품 종류가 다를 경우 매핑 정보를 숙지합니다.
3
사은품 재고 확인
대상 옵션별 사은품 재고가 충분한지 확인합니다.
4
WMS 자동 표시 여부 확인
WMS 피킹지시서에 옵션 수량 기준 사은품이 자동 표시되는지 확인합니다.
5
적용 기간 확인
해당 옵션 사은품 프로모션의 적용 기간을 확인합니다.
✅
출고 후 WMS에서 사은품 재고 차감까지 확인해야 재고가 정확히 관리됩니다.
처리 과정
STEP 1주문 내 옵션 및 수량 확인

WMS에서 주문 내 해당 옵션의 수량을 확인하고 사은품 기준 충족 여부를 판단합니다.

📷 주문 내 옵션 및 수량 확인 화면
STEP 2옵션 매핑 사은품 피킹

해당 옵션에 매핑된 사은품을 기준 수량에 맞게 피킹합니다.

📷 옵션 매핑 사은품 피킹 화면
STEP 3박스 내 동봉

본 상품 포장 시 사은품을 함께 동봉합니다.

📷 박스 내 동봉 화면
STEP 4출고 처리

일반 출고와 동일하게 처리합니다.

📷 출고 처리 화면
STEP 5사은품 재고 차감 확인

WMS에서 해당 사은품 재고 차감을 확인합니다.

📷 사은품 재고 차감 확인 화면
자주 하는 질문
각 옵션의 수량을 개별 확인하고, 기준을 충족하는 옵션에 해당하는 사은품을 각각 동봉합니다.
고객사 담당자에게 즉시 확인 요청합니다. 정보 확인 전까지 사은품 동봉을 보류합니다.
WMS에서 즉시 기준 수량을 업데이트합니다. 변경 전후 경계 시점 주문은 고객사와 처리 기준을 협의합니다.
고객사에 즉시 재고 소진 사실을 안내하고 대체 사은품 또는 추가 입고 여부를 확인합니다.
해당 옵션 사은품 설정을 WMS에서 비활성화합니다. 기존 재고가 남아 있다면 처리 방향을 고객사와 협의합니다.
